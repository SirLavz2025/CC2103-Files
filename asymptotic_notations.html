Asymptotic Notations & Java Analysis

Algorithm Efficiency & Asymptotic Analysis

Asymptotic notations are mathematical tools used to describe the running time or space complexity of algorithms by removing machine-dependent constants and focusing on how execution scales as input size ($n$) approaches infinity.

Big Oh ($O$) Upper Bound
Mathematical Definition

f(n) ≤ c · g(n) for all n ≥ n_0

Guarantees the maximum runtime behavior. The algorithm will never grow faster than this rate asymptotically.

Omega ($\Omega$) Lower Bound
Mathematical Definition

f(n) ≥ c · g(n) for all n ≥ n_0

Guarantees the minimum runtime behavior. The algorithm will at least take this much time to complete execution.

Theta ($\Theta$) Average/Tight Bound
Mathematical Definition

c_1g(n) ≤ f(n) ≤ c_2g(n)

Tight bound representing both upper and lower limits simultaneously. Highly accurate growth description.

Which One is Accurate?

Theta ($\Theta$) is mathematically the most accurate and complete bound because it bounds the algorithm from both above and below.

Is Big O = Worst Case?

NO! Big O is merely an upper bound. While often used for worst-case analysis, it can also describe best or average case behavior.

Asymptotic Properties
  • Transitivity: If $f = O(g)$ and $g = O(h)$, then $f = O(h)$.
  • Reflexivity & Symmetry: $\Theta$ is symmetric.
  • Transpose Symmetry: $f=O(g) \iff g=\Omega(f)$.

public class AsymptoticDemo {
    // Linear Search: Demonstrates O(n) Upper & Omega(1) Lower Bound
    public static int linearSearch(int[] arr, int target) {
        for (int i = 0; i < arr.length; i++) {
            if (arr[i] == target) return i; // Best Case: O(1)
        }
        return -1; // Worst Case: O(n)
    }
}
