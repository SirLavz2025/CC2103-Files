Number Series Solution

Series: 2, 6, 12, 20, 30, ?
Next Number: 42

Step-by-Step Solution

Method 1: Difference Analysis

  • 6 − 2 = 4
  • 12 − 6 = 6
  • 20 − 12 = 8
  • 30 − 20 = 10
  • Notice that the differences increase by +2 each time (4, 6, 8, 10...).
  • The next difference will be 10 + 2 = 12.
  • Next term: 30 + 12 = 42.

Method 2: Algebraic Formula (n × (n + 1))

  • Term 1 (n=1): 1 × 2 = 2
  • Term 2 (n=2): 2 × 3 = 6
  • Term 3 (n=3): 3 × 4 = 12
  • Term 4 (n=4): 4 × 5 = 20
  • Term 5 (n=5): 5 × 6 = 30
  • Term 6 (n=6): 6 × 7 = 42

Java Program (Recursive Method)

Using the recursive formula: a(n) = a(n-1) + 2n with base case a(1) = 2.

public class NumberSeries {

    // Recursive method to calculate the n-th term
    public static int getTerm(int n) {
        // Base case: first term in the series is 2
        if (n == 1) {
            return 2;
        }
        // Recursive call: previous term + (2 * n)
        return getTerm(n - 1) + (2 * n);
    }

    public static void main(String[] args) {
        int targetTerm = 6;
        int result = getTerm(targetTerm);
        
        System.out.println("The " + targetTerm + "th term in the series is: " + result);
    }
}
